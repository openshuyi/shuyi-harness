# 编码智能体 v0.4 设计 —— 交互与体验追赶计划

日期：2026-09-20
状态：实施基线（v0.3.1 全部完成后立项）

## 0. 背景与定位

v0.3.1 后，能力面（工具/权限/事件溯源/Skills/Hooks/worktree/ACP/TUI）已对齐第一梯队。
本版聚焦交互与体验（UX）：变更控制、上下文引用、协作节奏、可见性反馈、会话管理。

竞品基线（2026-09）：Claude Code（/rewind 检查点、/diff 持久面板、/context 用量区）、
Cursor（逐 hunk Keep/Undo、可编辑 Plan Mode、@引用）、Windsurf（暂存式编辑、消息排队、
Agent Command Center 看板、Previews 元素回传）、OpenCode（/undo /redo、命令面板）、
CodeBuddy（Plan 模式任务清单确认、@文件/知识库、/指令）。

### 设计红线（延续 v0.3 §0，逐条适用于本版全部特性）

1. 事件模型只增不改：新事件类型追加；payload 只加可选字段。
2. 权限 fail-closed：rewind/分叉/变更撤销等新入口同样不得绕过 PermissionService 语义
   （本版新 API 均为会话内本地操作，不引入新工具权限面）。
3. 本地优先：全部特性离线可用；预览面板等网络相关仅渲染用户自填 URL。
4. 向后兼容：不加表不加列（检查点走文件系统快照），仅新增事件类型。
5. 每步交付：dev:server + dev:web + bun test 全绿。

### 保留的差异化资产（不得在重构中削弱）

- question 工具三端适配（Web/TUI/ACP）；审批按命令行 glob 记忆
- hooks fail-closed + hook.executed 审计；离线 HTML 回放
- 事件溯源底座——本版 rewind/分叉/变更面板全部直接复用 seq 锚点

## 1. 特性清单与优先级

### P0（决定"敢不敢放手让 agent 跑"）

**F1 检查点 + rewind（对齐 Claude Code /rewind、OpenCode /undo）**
- 服务端 `checkpoint` 模块：每次变更类工具（write/edit/bash）执行**前**，若目标文件存在，
  快照至 `<cwd>/.agent/checkpoints/<sessionId>/<eventSeq>/<pathB64>`；事件 `checkpoint.created`
  于每个 turn 开始落库（锚点 seq）。
- API：`POST /api/sessions/:id/rewind {to_seq, mode: "code"|"conversation"|"both"}`。
  - code：按 seq 倒序恢复快照（后到先恢，避免互相覆盖），清理该 seq 之后目录；
  - conversation：追加 `session.rewound {to_seq, mode}` 事件；轨迹读取投影在该事件之后
    仅返回 seq<=to_seq 的消息/工具事件（append-only，历史可审计不物理删除）。
- Web：每个用户消息/turn 卡片悬浮「回滚」按钮 → 三选弹层（仅代码/仅会话/两者）。
- TUI：`/rewind [n]` 回到第 n 个 turn 锚点（仅代码+会话）。

**F2 变更面板（对齐 Cursor 逐 hunk、Windsurf 暂存审批）**
- API：`GET /api/sessions/:id/changes` —— 基于检查点快照（before）与当前文件（after）
  计算 unified diff，按文件聚合返回 `{path, diff, additions, deletions, status}`；
  `POST /api/sessions/:id/changes/review {path, action: "accept"|"revert"}`：
  accept 清理该文件快照（标记已审），revert 恢复快照内容；均落 `changes.reviewed` 事件。
- Web：右侧可开关「变更」面板，文件列表 + 内联 diff 渲染（增绿删红），逐文件
  接受/撤销；worktree 合并前展示面板入口。

### P1（协作节奏）

**F3 @ 文件引用**：`GET /api/sessions/:id/files?q=`（复用 glob，前 20 条）；
Composer 输入 `@` 弹补全（复用 slash palette 组件）；服务端 startTurn 展开 `@path`
为 `<file path="…">…</file>` 上下文块（单文件 8KB 截断，总量 32KB）。

**F4 消息排队 + 打断（Steering）**：busy 时 startTurn 进入会话内队列（内存），落
`message.queued` 事件；turn 结束自动出队执行；`POST /queue/:qid/cancel` 可撤回
（`message.queue_cancelled`）；Web 显示排队 chips + 「打断并发送」（abort 后立即发）。

**F5 计划 artifact 批准流**：plan 模式 turn 完成时最后一条 assistant 消息标记为计划提案；
Web 计划卡片 [批准执行] [编辑后批准]；`POST /api/sessions/:id/plan/approve {text?}`
→ 切 build（session.config_changed）+ 以确认消息开新 turn（带修订文本时附上）。

**F6 可见性与键盘体系**：
- Composer 底部常驻用量条（累计 in/out tokens、成本、上下文占比估算）——数据来自
  turn.completed usage 聚合，API `GET /api/sessions/:id/usage`。
- 命令面板 Ctrl+K：新会话/模式切换/主题/变更面板/回滚最近 turn/搜索会话。
- 快捷键：Esc（busy 打断 / 否则清空输入）、Ctrl+N 新会话、空输入 ↑ 召回上一条消息。
- 消息编辑重发：用户消息悬浮「编辑」→ 载入 Composer → 发送时自动 conversation-rewind
  至该消息前再发新文本。

### P2（体验抛光）

**F7 富渲染 + 完成提醒**：assistant 消息 Markdown 渲染（marked + 代码高亮），
```mermaid 代码块动态按需渲染；turn.completed 且页面不可见时系统通知 + 提示音。

**F8 会话看板**：SessionList 搜索框、按状态分组（进行中/等待审批/空闲）、置顶（localStorage）。

**F9 会话分叉**：`POST /api/sessions/:id/fork {to_seq?}` → 复制事件至新会话
（重排 seq，落 `session.forked` 事件标记来源），Web 在回滚弹层提供「从此分叉」。

**F10 内嵌预览**：右侧预览面板（地址栏 + iframe，URL 按会话存 localStorage），
「发送当前 URL 给 Agent」按钮；同源时可点选元素生成 CSS 选择器随消息发送
（跨域显示降级提示）。

## 2. 新增事件（只增）

| 事件 | payload | 说明 |
|---|---|---|
| checkpoint.created | {turn_seq, snapshot_dir} | turn 锚点 |
| session.rewound | {to_seq, mode} | 轨迹投影截断标记 |
| changes.reviewed | {path, action} | 变更审查审计 |
| message.queued | {queue_id, text} | 排队审计 |
| message.queue_cancelled | {queue_id} | 撤队审计 |
| session.forked | {from_session_id, from_seq} | 分叉来源（落在新会话） |

## 3. 验收

- 单测：checkpoint 快照/恢复顺序；rewind 三模式语义与投影截断；changes diff 聚合与
  accept/revert；队列 FIFO 与取消；fork 事件重排；@ 展开截断；plan approve 切模式。
- e2e：写两个文件 → rewind 仅代码（文件回、历史在）→ rewind 会话（轨迹截断）→
  分叉自锚点 → 新会话独立演进。
- 全量 bun test 绿 + 双端 typecheck + vite 构建 + 双主题截图目检。

## 4. 明确不做

- 逐 hunk 级 accept/reject（diff 算法复杂度高，先文件级；面板结构预留）；
- 云端异步 handoff（违反本地优先）；
- 跨会话持久化检查点清理策略（磁盘占用可接受，后续加 GC）。
