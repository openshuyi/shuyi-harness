品牌色探索 · Accent Explorer

靛蓝是 AI 工具类别最拥挤的色相（Linear / Warp / Arc / Obsidian 全在靛紫族）。但拥挤≠廉价——Linear 自己就是靛蓝，廉价来自饱和滥用，不来自色相。真正的命题是"能否拥有一个颜色"= 稀缺 × 纪律 × 叙事。语义系统已预订绿 / 红 / 黄 / 青四个信号色相，accent 的合法空间只剩四个：靛、橙、品红、无彩度。点击卡片，整页实时换肤。

electric indigo #6e6cf6 · hue 241°

现行品牌资产，改动成本为零。类别最拥挤——高级感只能靠纪律赢（本页即示范）。

signal orange #ff7847 · hue 16°

仪器叙事最强：Teenage Engineering、航空琥珀灯、合成器 LED。深色下按钮配墨色文字（TE 风）。代价：warn 需让位纯黄（本演示已联动）。

signal magenta #e34f97 · hue 333°

类别几乎无人使用，辨识度最高。风险：偏时尚感，与"静谧仪器"的冷静气质有张力——敢用就极有记忆点。

ink · achromatic #e9ebf0 · hue —

Geist / Cursor 路线：墨水即品牌，理论上限最高。代价："进行中"信号与交互色同质化，链接 / 焦点需要辅助功能蓝。
