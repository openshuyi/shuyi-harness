## 0. 一句话定位

**同一具仪器的东方骨头与皮肤：深色是墨，浅色是纸，交互是天青瓷，批准是盖朱印。**

v1「静谧仪器」用西方极简解决了"克制"；v2「墨仪」回答——克制的高级感可以是中国的。方法不是贴纹样，是进口中国艺术的**组织原则**；v2.1 定稿两个开放决策：**宋体标题轨保留（中文读品气质）**，**天青为默认交互色（朱砂退为印章专属）**。

## 1. 方法论：进口结构，不贴纹样

| 源泉 | 进口的智慧 | 落地 |
|---|---|---|
| 宋人美学 | 素雅、克制、内敛的品位基准 | 整体气质的千年出处 |
| 墨分五色 | 焦浓重淡清——水墨明度分层 | 深色主题五层表面（§3.1） |
| 宣纸 | 帘纹暖象牙白 | 浅色主题（§3.3） |
| 汝窑天青 | 「雨过天青云破处」 | 交互色：瓷面的冷静与温润（§3.4） |
| 朱砂印章 | 一幅画上唯一一点红 = 信号；盖印 = 授权 | 印章专属色 + 审批盖印仪式（§5） |
| 宋版书 | 界行、宋体标题、刊本气质 | 发丝线谱系 + 宋体标题轨（§4） |
| 榫卯 | 结构接合，不用装饰钉 | "层次靠线不靠影"的东方表述 |
| 园林 · 框景/借景 | 以窗取景、景随步移 | 右面板 = 框景，预览面板 = 借景 |
| 拓片 · 碑帖 | 白文于墨 | 深色主题的文本气质（暖白于暖黑） |

## 2. 设计原则（六条）

1. **墨即是界面，纸即是界面。** 主题不是 dark/light 二进制，是墨与纸两种材质；墨分五色定层，纸有帘纹定温。
2. **交互用天青，仪式用朱砂。** 全部交互承载于汝窑天青；朱砂只属于印章（品牌印、「准」印、批准动作）——青瓷色的界面上，唯一的红是印。
3. **色彩即颜料，颜料即信号。** 天青（交互）、茜红（危险）、藤黄（警示）、石绿（成功）、青瓷（信息）——五个颜料名就是五条语义。
4. **宋标黑文，mono 读数。** 三轨制排版：标题宋体（读品气质），正文黑体，读数 mono。
5. **层次靠榫卯，不靠阴影。** 表面步进与发丝线是榫与卯；阴影只属于浮层。
6. **计白当黑。** 留白是主动设计；拒绝不盖章——留白即否。

## 3. Design Token 体系

### 3.1 深色 · 墨五色

| Token | 墨名 | 值 | 用途 |
|---|---|---|---|
| `--bg-0` | 焦墨 | `#0f0e0d` | 画布 |
| `--bg-1` | 浓墨 | `#151413` | 一级面板 |
| `--bg-2` | 重墨 | `#1c1b19` | 卡片 |
| `--bg-3` | 淡墨 | `#242320` | 浮层 |
| `--bg-inset` | 沉墨 | `#0a0908` | 凹陷读数区 |

文本 `#edebe6 / #9d9a94 / #63615c`（暖白系）；线 `rgba(255,246,235,.055/.10/.165)`（暖调发丝）。

### 3.2 浅色 · 宣纸

生纸 `#f3f0e9` / 熟纸 `#f7f5ee` / 卷面 `#fcfbf7` / 帘纹 `#edeadf`；文本 `#211f1c / #5a5750 / #98948c`；线 `rgba(32,28,20,.07/.12/.19)`。主题切换即**墨 ⇄ 纸**。

### 3.3 交互色 · 天青（v2.1 定稿）

| Token | 墨主题 | 纸主题 | 说明 |
|---|---|---|---|
| `--accent` | `#8ab4d9` | `#2e6ea6` | 汝窑天青；墨主题配墨字 `#101c28`（瓷面），纸主题配白字（4.9:1） |
| `--accent-hover/active` | `#a3c5e2` / `#75a3c8` | `#255d8e` / `#3a7cb4` | |
| `--accent-soft / ring` | 15% / 45% | 10% / 40% | |

**决策依据**：① 与"静谧仪器"气质同构——瓷的冷静温润甚于火的热烈；② 与全部语义颜料无色相冲突（208° 独占）；③ 类别（AI dev tool）中蓝灰瓷调罕见且不落"默认蓝"俗套（低饱和灰调是关键）；④ 朱砂得以下放印章，稀缺性归位。第 16 节试验场保留回溯候选：朱砂 / 青金（v1）/ 松烟。

### 3.4 印章色 · 朱砂（不随品牌色浮动）

| Token | 墨主题 | 纸主题 | 用途 |
|---|---|---|---|
| `--seal` | `#d64730` | `#b23415` | 品牌印 / 「准」印 / **批准按钮 `.b-seal`** / 空态印 |
| `--seal-hover` | `#e4654e` | `#9c2d11` | |
| `--seal-soft` | 14% | 10% | 印章光晕/选底 |

### 3.5 语义 · 颜料（固定）

| 语义 | 颜料 | 墨主题 | 纸主题 |
|---|---|---|---|
| danger | 茜红 | `#ef5f7d` | `#c73a5c` |
| warn | 藤黄 | `#f0b34e` | `#a8741c` |
| success | 石绿 | `#35b98a` | `#0f8f66` |
| info | **青瓷** | `#62c2cf` | `#0e7d8a`（v2.1 由群青调整——与天青拉开青绿相，避免与交互色同族） |

## 4. 排版 · 三轨制（v2.1 确认）

```css
--font-serif: "Noto Serif SC", "Songti SC", "STSong", serif;
--font-sans:  "Inter", …, "PingFang SC", …;
--font-mono:  "JetBrains Mono", …;
```

标题（Display 25 / h2 21 / h3 / 弹窗与计划卡标题 / 分区标题）用宋体 600，微正字距 +0.01em（宋体不适用负字距）；正文黑体；读数 mono（v1 清单不变）。**中文读品气质**由标题轨承担——正文与数据保持现代可读性，古典只出现在"署名处"。落地 `@fontsource-variable/noto-serif-sc` 自托管。

## 5. 印章仪式 · Seal Ritual

1. **品牌印**：26px 朱砂方印（`--seal`）、内圈刻边（inset 1px 22% 白）、白文「书」宋体 700。印文字样属品牌决策，当前以「书」演示。
2. **批准印**：审批通过，「准」印落轨迹——38px 方框印（1.5px 朱砂描边、5px 圆角、宋体 700、旋转 -4°、92% 不透明度）。**批准按钮 `.b-seal` 用朱砂**（唯一红色操作），其余 primary 全部天青。
3. **盖章动效**：`stampIn` 280ms ease-pop——scale 1.35→0.96→1 落定、3°→-4° 旋转收正、0.6px 墨晕散焦。一次性，不自动重复。
4. **拒绝不盖章**：留白即否（茜红文字 + ⓧ，无印）。
5. **空态印**：「书」印承接 v1 渐变的仪式位。**渐变正式退役**，`--brand-gradient` 保留为纯色别名以兼容。
6. 印只此三处 + 批准按钮。印不可滥用。

## 6. 交互规格 · Motion & Interaction（v2.1 新增，设计稿第 22 节可操作）

| 交互 | 规格 | 备注 |
|---|---|---|
| hover / focus | 140ms ease | 边框与亮度变化，位移禁止 |
| 展开 / 折叠 / 面板 | 200ms ease | 工具卡、右面板、tabs |
| 弹窗 / 命令面板 | 280ms ease-pop | 轻度过冲；遮罩 `blur(3px) saturate(1.3)` |
| **盖章 stamp-in** | 280ms ease-pop 一次性 | 全系统唯一"重"动效 |
| 流式渲染 | 28ms/字 + 2px caret `steps(1)` | 光标是节拍器 |
| 命令面板 ⌘K | 输入即过滤 · ↑↓ 导航 · ⏎ 执行 · Esc 关闭 | 全局唯一动作入口；菜单/右键是其鼠标等价物 |
| 右面板 tabs | 下划线 accent 2px + 200ms 内容切换 | 框景切换 |
| 列表入场 stagger | 45ms/项 · 位移 4px · 320ms | 遵守 prefers-reduced-motion |

键盘体系沿用 v0.4 F6：Esc 打断/清空、Ctrl/⌘N 新会话、空输入 ↑ 召回、⌘K 面板。

## 8. 残留风险

1. 天青与青瓷（info）色相 208° vs 187°——墨主题下 `#8ab4d9` vs `#62c2cf` 亮度接近，若实测混淆，青瓷可再向绿偏移或降低亮度。
2. 宋体标题在西文混排（如「变更审查 Changes」）需目检字重平衡；纯西文标题回退 serif 拉丁字形（Noto Serif SC 含拉丁）。
3. 印文字样（书/准）与天青精确色值（汝窑谱系内仍有跨度）属品牌最终决策。
