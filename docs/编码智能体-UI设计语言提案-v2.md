## 0. 一句话定位

**同一具仪器的东方骨头与皮肤：深色是墨，浅色是纸，批准是盖章。**

v1「静谧仪器」用西方极简（Geist/Linear 语系）解决了"克制"；v2「墨仪」回答下一个问题——**克制的高级感，能不能是中国人的？** 答案不是贴纹样，而是进口中国艺术的结构智慧：宋人美学早于现代极简一千年完成了这套实践。

---

## 1. 方法论：进口结构，不贴纹样

廉价中国风 = 纹样粘贴（窗棂、祥云、水墨背景图）。高级中国风 = **结构进口**——把中国艺术的组织原则翻译为设计系统规则：

| 源泉 | 进口的不是 | 进口的是 | 落地为 |
|---|---|---|---|
| 宋人美学 | 宋画题材 | 素雅、克制、内敛的品位基准 | 整体气质：v1 已有的 calm design 找到千年出处 |
| 墨分五色 | 墨的颜色 | 焦浓重淡清——水墨画的明度分层系统 | 深色主题五层表面（§3.1） |
| 朱砂印章 | 印章图案 | 一幅水墨上唯一一点红=信号；盖印=授权动作 | 交互色朱砂 + 审批盖印仪式（§5） |
| 宋版书 | 古籍版式 | 界行（栏线）、宋体标题、行款节奏 | 发丝线谱系 + 宋体标题轨（§4） |
| 榫卯 | 家具造型 | 结构接合，不用装饰钉 | "层次靠线不靠影"的东方表述（v1 原则保留，换血统） |
| 园林 · 框景/借景 | 亭台楼阁 | 以窗取景、景随步移 | 右面板=框景（变更审查）、预览面板=借景（叙事命名） |
| 拓片 · 碑帖 | 拓片质感 | 白文于墨——dark mode 的千年原型 | 深色主题的文本气质（暖白于暖黑） |

## 2. 设计原则 v2（六条，承接 v1 演进）

1. **墨即是界面，纸即是界面。** 深浅主题不是 dark/light 二进制，是墨与纸两种材质。墨分五色定层，纸有帘纹定温。
2. **色彩即颜料，颜料即信号。** 朱砂（交互）、茜红（危险）、藤黄（警示）、石绿（成功）、群青（信息）——五个传统颜料名就是五条语义。彩色是数据，不是装饰（v1 铁律不变，获得文化血统）。
3. **盖印即批准。** 唯一的仪式动作授予权限流：审批通过，「准」印落在轨迹上。拒绝不盖章——留白即否。渐变正式退役。
4. **宋标黑文，mono 读数。** 三轨制：标题用宋体（宋版书血统），正文用黑体，读数用 mono（v1 双轨升级）。
5. **层次靠榫卯，不靠阴影。** 表面步进与发丝线是榫与卯；阴影只属于浮层（v1 原则，换东方表述）。
6. **计白当黑。** 留白是主动的设计动作（书写时白与黑同样经营），不是"没放东西"。

## 3. Design Token 体系 v2

### 3.1 深色 · 墨五色（替换 v1 蓝灰四层）

| Token | 墨名 | 值 | 用途 |
|---|---|---|---|
| `--bg-0` | 焦墨 | `#0f0e0d` | 画布（侧栏底、body） |
| `--bg-1` | 浓墨 | `#151413` | 一级面板 |
| `--bg-2` | 重墨 | `#1c1b19` | 卡片（消息、工具卡、输入区） |
| `--bg-3` | 淡墨 | `#242320` | 浮层（弹窗、菜单） |
| `--bg-inset` | 沉墨 | `#0a0908` | 凹陷读数区（代码、diff、终端） |

关键变化：v1 的蓝灰科技调 → **暖中性墨调**（如拓片碑帖）。步进约 3% 亮度，五层齐整对应焦浓重淡清（沉墨为"清"之下的积墨）。

### 3.2 深色文本与线（暖白 · 暖调发丝）

| Token | 值 |
|---|---|
| `--text-1/2/3` | `#edebe6` / `#9d9a94` / `#63615c`（暖白系） |
| `--line-1/2/3` | `rgba(255,246,235,.055 / .10 / .165)` |

### 3.3 浅色 · 宣纸（替换 v1 冷白）

| Token | 纸名 | 值 |
|---|---|---|
| `--bg-0` | 生纸 | `#f3f0e9` |
| `--bg-1` | 熟纸 | `#f7f5ee` |
| `--bg-2` | 卷面 | `#fcfbf7` |
| `--bg-inset` | 帘纹 | `#edeadf` |
| text | | `#211f1c` / `#5a5750` / `#98948c` |
| line | | `rgba(32,28,20,.07/.12/.19)` |

主题切换即 **墨 ⇄ 纸**（UI 文案与 toggle 字样用「墨」「纸」）。

### 3.4 交互色 · 朱砂（开放决策的 v2 默认解）

| Token | 墨主题 | 纸主题 | 说明 |
|---|---|---|---|
| `--accent` | `#d64730` | `#b23415` | 印泥色；白字对比 4.5:1 |
| `--accent-hover/active` | `#e4654e` / `#bf3b25` | `#9c2d11` / `#c64425` | |
| `--accent-soft / ring` | 14% / 45% alpha | 10% / 40% | |
| `--brand-gradient` | **退役** | **退役** | 仪式移交盖印；token 保留为纯色别名以兼容 |

**为什么朱砂**：① 类别稀缺——AI 工具无人用暖红做交互色，可拥有性最强；② 叙事契合——印章红是"授权/落款"的千年符号，与 fail-closed 权限体系同构；③ 与茜红 danger 拉开色相（11° vs 342°），靠暖朱与冷玫区分，且危险恒伴 ⓧ 图标。第 16 节试验场保留四候选实时换肤：**朱砂（默认）/ 天青（汝窑）/ 青金（v1 靛回归）/ 松烟（无彩度）**。

### 3.5 语义 · 颜料（固定，不随品牌色浮动）

| 语义 | 颜料 | 墨主题 | 纸主题 |
|---|---|---|---|
| danger | 茜红 | `#ef5f7d` | `#c73a5c` |
| warn | 藤黄 | `#f0b34e` | `#a8741c` |
| success | 石绿 | `#35b98a` | `#0f8f66` |
| info | 群青 | `#7d84ea` | `#4b4fc4`（v1 靛蓝降格为信息色——旧主色不除名） |
| idle | 黛 | `--text-3` | 同 |

## 4. 排版 · 三轨制（升级 v1 双轨）

```css
--font-serif: "Noto Serif SC", "Songti SC", "STSong", serif;   /* 新增 */
--font-sans:  "Inter", …, "PingFang SC", …;                      /* 沿用 */
--font-mono:  "JetBrains Mono", …;                               /* 沿用 */
```

| 轨 | 字体 | 用途 | 血统 |
|---|---|---|---|
| 标题 | 宋体 600（Noto Serif SC） | Display / h2 / h3 / 弹窗与计划卡标题 / 分区标题 | 宋版书标题轨 |
| 正文 | 黑体（Inter + Noto Sans SC） | body / body-dense / 列表 | 现代 UI 可读性 |
| 读数 | mono | label-mono 及一切仪器读数（v1 清单不变） | 终端血统 |

- Display 级改为 **25px 宋体 600 / +0.01em**（宋体不适用负字距，微正字距显刊本气质）。
- 落地：`@fontsource-variable/noto-serif-sc` 自托管（本地优先）。
- 中文标签在 label-mono 中字距 +0.06em 同样适用（「墨」「纸」「已批准」）。

## 5. 印章仪式 · Seal Ritual（v2 签名动作）

1. **品牌印**：logo = 26px 朱砂方印、内圈刻边（inset 1px 22% 白）、白文「书」（shuyi = 书艺；印文字样待品牌定夺，技术上是 `--font-serif` 700 反白）。
2. **批准印**：审批通过后，轨迹流上落「准」印——38px 方框印（1.5px 朱砂描边、5px 圆角、宋体 700、**旋转 -4°**、92% 不透明度），盖在 approval 事件行右侧。盖章动效：scale 1.15→1 + 旋转落定，280ms ease-pop（一次性，不重复）。
3. **拒绝不盖章**：留白即否——拒绝行只有茜红文字与 ⓧ，无印。负空间的使用是计白当黑的第一现场。
4. **空状态印**：空状态用「书」印替代 v1 渐变 glyph（渐变退役的承接）。
5. 印章只此三处：品牌印、批准印、空态印。**印不可滥用**——盖印的价值在于稀缺（同 v1 渐变纪律）。

## 6. v1 → v2 变更清单（迁移指引）

| 维度 | v1 静谧仪器 | v2 墨仪 | 迁移动作 |
|---|---|---|---|
| 深色表面 | 蓝灰四层 `#090b10→#1f2431` | 墨五色 `#0f0e0d→#242320` + 沉墨 | 换 5 个 token 值 |
| 浅色表面 | 冷白 `#f5f5f1` 系 | 宣纸 `#f3f0e9` 系 | 换 5 个 token 值 |
| 文本/线 | 冷调 | 暖白 / 暖调发丝 | 换 token 值 |
| 交互色 | 电光靛 `#6e6cf6` | 朱砂 `#d64730` | 换 token 值；靛降格为群青 info |
| 语义色 | 通用 success/red/yellow/cyan | 石绿/茜红/藤黄/群青 | 换值+命名 |
| 渐变 | 品牌仪式（logo/空态） | **退役**，仪式=盖印 | 移除 `--brand-gradient` 使用点 |
| 标题字体 | Inter 600 | 宋体 600 三轨制 | 引入 serif 变量，替换标题 font-family |
| 主题文案 | Dark / Light | 墨 / 纸 | 文案 |
| 新增组件 | — | seal（品牌印/批准印/空态印） | 新 CSS 类 + 盖章动效 |
| machined edge | 冷白顶光 | 暖白顶光 `rgba(255,246,235,.04)` | 换 2 处 rgba |
| 其余 | — | **全部沿用 v1** | 排版阶梯/组件规格（§6）/应用框架（§11.1）/菜单表单数据（§11.2-11.4）/图标系统（§11.5）/高级感工程（§10）/主题机制统一（§7） |

shadcn 槽位映射表沿用 v1 §7；`--radius` 维持 0.5rem；动效 token 不变。

## 7. 开放决策与风险

1. **宋体标题**是 v2 最大胆的一步：中文产品语境中极高级（读品气质），但 dev tool 类别无先例——建议先在第 14 节工作台整体目检，若违和可退回 Inter 标题（其余 v2 改动不受影响）。
2. **朱砂 vs 茜红**色相差 31°，靠暖朱/冷玫 + ⓧ 图标双保险区分；若实测混淆，茜红可再向玫红偏移。
3. 印文字样（书/准/舒）属品牌决策，本提案以「书」「准」演示。
